# 📈 Projeto Monitora+

Está aplicação tem como objetivo realizar a gestão e monitoramento dos produtos em estoque, apresentando dados através de gráficos e tabelas para análise completa.

## 📌 Funcionalidades

### 👤 Usuário
- Analisar gráficos
- Visualizar lista de itens em estoque/solicitados
- Receber dicas através de IA ao verificar os dados
- Verificar calendário que apresentará as datas de entrega dos produtos

## 🚀 Tecnologias Utilizadas

- **Frotend:** Html, Css e JavaScript
- **Backend:** Node.js e Express.js
- **Banco de Dados:** MySQL
- **Segurança:** A decidir...
- **Documentação:** Swagger, JSDoc e Docs
- **Versionamento:** Git e GitHub
- **Bibliotecas:**
  - Bootstrap icons
  - FullCalendar
  - SweetAlert2
